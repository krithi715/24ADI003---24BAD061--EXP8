This project demonstrates two important data mining and machine learning techniques: Association Rule Mining using the Apriori Algorithm and Dimensionality Reduction using Principal Component Analysis (PCA). In the first scenario, transactional data from the Groceries Dataset (available at https://www.kaggle.com/datasets/heeraldedhia/groceries-dataset
) is used to identify frequent itemsets and generate meaningful association rules based on support, confidence, and lift. The workflow includes preprocessing transactions into one-hot encoded format, applying Apriori to discover patterns, and analyzing strong relationships between items. In the second scenario, PCA is applied to a numerical dataset such as the Wine Dataset to reduce dimensionality while preserving maximum variance. The project includes data preprocessing, feature scaling, computation of principal components, and visualization through scree plots and scatter plots. Together, these tasks provide insights into pattern discovery and efficient data representation for real-world applications.
